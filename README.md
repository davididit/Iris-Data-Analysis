# Iris Data Analysis

This repository contains two Python exercises using the Iris dataset.

## Exercise 1: Data Analysis
- Load and explore the dataset
- Calculate summary statistics
- Check for missing values
- Create data visualizations

## Exercise 2: Decision Tree Classification
- Prepare the dataset
- Split the data into training and testing sets
- Train a decision tree classifier
- Predict flower species
- Evaluate accuracy, precision, and recall

## Files
- Iris.csv: The dataset
- exercise1_eda.py: Data analysis program
- exercise2_decision_tree.py: Decision tree classification program

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
